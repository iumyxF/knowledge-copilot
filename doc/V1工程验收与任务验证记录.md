## 2. 本次交付范围

### 2.1 已实现

- `server/`：Java 21 单 Maven 模块后端，模块化单体结构。
- `web/.gitkeep`：仅预留前端目录，无前端业务代码。
- Knife4j 接口文档与在线调试，不做登录认证。

- 文档异步解析、清洗、切片、Embedding、ES 索引及状态查询。
- 失败重试、处理批次隔离、重启恢复和幂等删除。
- 单轮非流式问答、实际上下文引用、无检索结果时固定拒答。
- 评测集与用例管理、JSON 导入、异步评测、运行快照及结果查询。
- 文档级 Recall@5、Recall@10、MRR@10、Hit Rate@10。
- 五份自编中文资料、失败样本、20 条示例评测用例及导入辅助脚本。

## 6. 关键工程验证明细

### 6.1 数据库迁移与业务状态

- 两批 Flyway 迁移建立七张业务表，首次迁移及重复启动校验正常。
- 知识库与文档管理、评测管理及相关状态转换在真实 MySQL 中执行通过。
- 同一失败文档并发重试仅一个请求成功领取，其他请求返回状态冲突。
- 部分索引写入失败的文档不进入 AVAILABLE，不参与有效检索。
- 队列拒绝及应用重启中断可查询明确失败原因，并允许显式重试。
- 删除失败后文档维持不可检索状态，再次删除可继续清理。

### 6.2 Elasticsearch

- 使用确定的 embeddingId 重复写入，未产生重复有效记录。
- 检索按 knowledgeBaseId、documentId 和 attemptNo 过滤。
- 全部写入后刷新并检查可搜索数量，再标记文档可用。
- 相同维度但模型标识变化时，已有索引也会被拒绝使用。
- 文档所有批次数据可清理，重复删除幂等成功。
- 本地 ES 测试使用固定向量及随机测试索引，结束时仅清理自身索引。

### 6.3 受控模型端到端链路

通过真实 MySQL、真实 ES 和本地临时模型协议服务完成：

1. 上传 PDF、DOC、DOCX、TXT、Markdown 五份示例文件。
2. 等待全部文档进入 AVAILABLE。
3. 经 LangChain4j 模型集成与 AiServices 获取受控答案，引用来自实际检索切片。
4. 在空知识库提问，确认固定拒答且未增加 Chat 调用。
5. 导入并执行 20 条评测用例，保存完整结果。
6. 确认检索评测只调用 Embedding，不调用 Chat。
7. 删除文档后再次提问，确认无法继续检索这些文档。

该测试验证真实服务之间的数据流和模型协议接入，不提供真实语义检索与生成质量结论。

### 6.4 构建、JAR 与实际 HTTP

- 主 Java 代码编译通过。
- 全套测试通过后，离线打包因缺少 Boot 插件依赖未完成。
- 下载缺失依赖后执行 `mvn -f server/pom.xml -DskipTests verify`，打包结果为 BUILD SUCCESS；此步骤用于打包，不重复声称执行了测试。
- 生成可运行产物：`server/target/knowledge-copilot-1.0.0-SNAPSHOT.jar`。
- 使用 `java -jar` 启动并连接真实 MySQL，模型保持禁用。
- `/doc.html` 和 `/v3/api-docs` 实际 HTTP 返回 200，OpenAPI 版本为 3.0.1。
- 实际 HTTP 完成知识库创建、分页查询及删除，返回 ID 为字符串。

## 7. 验证中发现并解决的问题

| 问题 | 处理方式 | 验证结果 |
| --- | --- | --- |
| Knife4j 4.5.0 旧增强定制器与 springdoc 2.8 方法签名不兼容 | 关闭旧服务端增强定制器，保留 Knife4j UI 和调试能力 | OpenAPI 生成及实际文档请求成功 |
| DOCX 解析遇到 commons-compress 方法缺失 | 固定 1.27.1，与 POI 5.4.1 对齐 | DOCX 上传和解析测试通过 |
| Windows Maven 命令行 URL 中的 & 被 .cmd 解释 | 测试命令使用无额外查询参数的 URL；应用启动通过环境变量传完整 URL | 真实 MySQL 测试通过 |
| 本机全局 CLASSPATH 引用了不存在的旧 JDK dt.jar，导致 ES 启动失败 | 只在临时 ES 启动进程中清空 CLASSPATH，不修改系统全局设置 | ES 8.18.8 成功启动并通过测试 |
| 离线打包缺少 Spring Boot 插件依赖 | 下载缺失依赖后单独完成打包 | 可运行 JAR 生成并启动成功 |
