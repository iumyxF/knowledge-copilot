## 验证记录（2026-09-11）

环境：Windows、Java 21.0.10、Maven 3.9.14、MySQL 8.0.45、Elasticsearch 8.18.8。

1. 全套测试共 38 项：36 项通过，0 失败，0 错误，2 项跳过。跳过的是 Docker 容器测试；本机没有 Docker，已另外用本地真实 MySQL 和 ES 执行对应能力验证。
2. ApiSmokeTest、PipelineLifecycleTest、EvaluationWorkflowTest 合计 13 项，另在真实 MySQL 8.0.45 上全部通过。两批 Flyway SQL 迁移及重复启动校验正常。
3. LocalElasticsearchTest 在真实 ES 8.18.8 上验证重复写入不新增有效记录、知识库与 attemptNo 过滤、模型指纹变化拒绝、全部批次删除及重复删除。
4. EndToEndTest 使用真实 MySQL + ES + 本机临时 OpenAI-compatible 协议替身：五份文件入库到 AVAILABLE，AiServices 返回受控答案及真实切片引用，空库不调用 Chat，20 条评测完成，删除后无法继续检索。
5. 可运行 JAR 已生成：server/target/knowledge-copilot-1.0.0-SNAPSHOT.jar。Java -jar 启动后，/doc.html、/v3/api-docs 均为 HTTP 200；知识库创建、分页和删除成功，ID 按字符串返回。
6. 依赖兼容修复：保留 Knife4j UI，关闭与 springdoc 2.8 不兼容的旧增强定制器；commons-compress 固定为 1.27.1，与 POI 5.4.1 对齐，DOCX 解析通过。

构建过程先执行全套测试，离线打包发现缺失的 Boot 插件依赖；下载后单独执行 `mvn -f server/pom.xml -DskipTests verify` 打包成功，没有重复调用已经通过的测试。

详细命令与重现步骤见 server/README.md；本次构建日志在 server/target 中，属于忽略的构建产物，不提交仓库。
